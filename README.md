Mattress Sales Application

Project Description

The Mattress Sales Application is a Java-based application developed to manage mattress sales. It allows users to enter customer details, select mattress products, calculate VAT and commission, and save sales information to a text file.

Products

Cozy Nights Monarch
Restonic Barbados
Sealy Phuket
Features

Customer name input
Mattress product selection
VAT calculation at 15%
Commission calculation at 5%
Automatic total calculation
Sales details saved to data.txt
File and Tools menu options
Unit testing using JUnit
Technologies Used

Java
Java Swing
Apache NetBeans
JUnit 4
